## 3. 体系一分钟速览

**组织**：用户（唯一破闸授权人）＋ 五 Agent：
输入腿（宏观基本面×量化技术）→ 统合层（首席策略师）→ 支援层（通用助手记账归档×全栈数据管道）。

**核心纪律**（节选，全部代码化）：
- 五闸：地缘 L0-L3 天花板 / 个股合计 28% / 单标的 12%÷(ATR%×3) 封顶 15% / 主题仓 C17 状态机 / 总权益 32-75% 按周期波动
- 十信号 AI 周期监测：WATCH→ALERT→LATE→END，半分摆动不翻转状态闸
- 九条铁律：收盘确认制、限价不追高、事件窗只减不加、单笔≤0.5%、纸面措辞分级…
- 任何"移出"必附翻案条件；升级只加纪律不加自由；两轮复盘同向才升格正式条款

**已验证的方法论资产**：
- 复盘三层计分揭示"框架层 80-83% vs 介入层 2/9" → 9/24 双轮同向后 C20-C22 升格 v1.3
- 双源核验 SOP：快照漂移>0.5% 进勘误带、收盘口径判决、代码映射必核（XOM 误标判例沉淀）

## 4. 评审者最有价值的三个切入点

1. **跑 `gates` 改参数**：五闸数值是经验值。试试把主题闸 12% 改成 8%/15%，
   看 `tests/test_gates.py` 里哪些断言会破——暴露我们对"多少算超限"的隐性假设。
2. **挑战 `clauses.py` 条款状态**：18 条正式条款中哪些其实证据不足？模拟 3 条
   （PEAD/13D/收缩突破）的验证路径是否可证伪？
3. **检查 `review.py` 验收门槛**：五闸验收（触发正确率≥65%…）与实盘准入链
   （G2 全过＋用户批准→教学仓）是否存在逻辑漏洞。

详细开放问题见 **docs/REVIEW_GUIDE.md**。

## 5. 诚实声明（体系已知短板）

- 纯纸面推演体系，**零实盘记录**；所有执行线为纸面挂单
- 仓位公式基于 ATR 近似，未含相关性/组合波动模型
- 双源核验依赖免费数据通道，存在同源污染风险（腾讯日K污染=工作假设待证伪）
- 条款库文本为人工维护，存在条款间潜在冲突未穷举
- 五 Agent 协作链路单点依赖首席统合，无首席缺位时的仲裁替代方案

以上每一条都是改进提案的欢迎方向。
