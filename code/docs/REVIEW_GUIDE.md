## 交付建议格式

任选切入点，提案请尽量包含：
1. **问题重述**（确认理解一致）
2. **最小改动方案**（落在本包哪个模块、改哪个参数/函数）
3. **可证伪的验证路径**（我们守则：升级只加纪律不加自由，验证失败永久撤回）
4. **风险**（新方案会破坏哪些现有判例）

> 注：本包所有数值均为框架层默认值；行情触发的"当前闸值"以纸面执行台账为准。
> 隐私层（用户画像/个人决策手册/收入细节）已刻意排除在打包范围外。
