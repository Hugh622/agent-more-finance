## 二、口径锚定（黄金公式，机器级钉死）

> 来源：红队盲审脚本口径经裁决书官方化。**我已独立重放 82 日窗全量复现**（逐项对照钉档 JSON：R1/R2/R3/R4 全对、六源 sha256+行数一致），此口径即 checker 的 B 源公式。

1. **数据源（六源钉档）**：`market_data/daily/` 下 usspy_am.csv / usqqq_oq.csv / usgldm_am.csv / usspcx_oq.csv / uszeta_n.csv / usnow_n.csv，**未复权 close**，六源**共同交易日交集**（当前窗 2026-06-12→2026-10-08，82 日）。sha256 钉档见 `黄金基线/nav_golden_replay.json` evidence 节，任一变更即整包升版。
2. **日收益**：r_A(t)＝mean(SPY,QQQ,GLDM 当日收益)；r_B(t)＝mean(SPCX,ZETA,NOW)；**r_p(t)＝0.5·r_A＋0.3·r_B＋0.2×0**（现金记 0）。
3. **NAV 递推**：NAV(t)＝NAV(t−1)×(1+r_p(t))，起点 1.0（数据窗首共同交易日）。该式等价于**日再平衡等权**。
4. **层拆分定义**：layer_a(t)＝0.5×NAV(t)、layer_b(t)＝0.3×NAV(t)、cash(t)＝0.2×NAV(t)——日再平衡口径下的必然恒等式（红队脚本不产出层序列，故此定义为工程侧落表约定）。若未来改持仓漂移口径，须走 §七 升版。
5. **三个触发读数**：
   - 周内回撤 WDD＝(周内 NAV 峰−当周最后交易日收盘 NAV)/周内峰；
   - 滚动峰累计回撤＝(历史最高水位−当周最后交易日收盘 NAV)/历史最高水位。⚠️**峰锚定义＝全部日度 NAV 的滚动最大值（含周内高点），严禁用周五收盘序列近似峰**；
   - 月回撤＝自然月内峰→月末（D2 口径）。

> **为什么钉这么死**：本次重放中，两种"诚实实现"仅因滚动峰取「周内高点」还是「周五收盘」就分歧 2.2 个百分点（5.62% vs 7.83%）——§3.5 防的就是这个。该分歧案例已入 §七 回归基线。

## 三、三源对账模型

| 源 | 内容 | 角色 |
|---|---|---|
| A 源 | nav_daily 表行（工程输出） | 被校验对象 |
| B 源 | 量化校验器独立重算（冻结六源＋黄金公式） | 独立复核 |
| C 源 | 首席手工基线（红队同款脚本口径） | 仲裁兜底 |

- **例行（每周）**：A vs B 逐日对表；C 源未更新周由 B 源代位，C 源每月至少抽检一次。
- **首检（10/16）**：A/B/C 三源逐日对表，报告随周检归档。
- **容差三档**（A vs B 相对偏差 |Δ|/NAV）：
  - ≤0.01%（1bp）→ **PASS**；
  - (0.01%, 0.05%] → **WARN**，须在报告中注明差异来源（复权口径/数据通道/舍入），未注明视同 FAIL；
  - >0.05% → **FAIL**：立 decision（main=RULE_VIOLATION，sub=DATA_CONFLICT，最终措辞以 reason_code registry 为准），**以 C 源手工值为准**，48h 内修复重跑；DD 层读取手工值，不阻塞生效。
- **恒等式容差**（独立于上）：|total_nav−(layer_a+layer_b+cash)| ≤ 1e-6（绝对值，纯舍入级）。

## 四、校验规则包 L0–L5（checker 实现清单）

- **L0 完整性**：nav_date 唯一（单组合一行）；七必需字段（§八）NOT NULL；NAV 四值 >0；币种单一 USD；proxy_universe_version/data_run_id 非空且可解析到宇宙注册表/冻结清单。
- **L1 日历连续性**：以美股交易日历为准（当前宇宙全为美股+现金）；美股交易日必须有行、非交易日禁止出现伪造行；**周五（若为交易日）必有一行**——DD 触发的收盘确认锚；断档 ≥3 个交易日→警报。
- **L2 恒等式**：§三恒等式＋权重比 layer_a:layer_b:cash＝0.5:0.3:0.2（±1e-6）——偏离即说明实现混入了漂移权重口径，标记口径不符。
- **L3 重算对账**：逐日 A vs B 黄金公式；触发读数（WDD/滚动峰/月DD）由 nav_daily 派生并与 B 源重算一致（0.01 个百分点粒度）。
- **L4 变异警戒**：组合日收益 |r|>15% → 拒绝入库等权组合不可能量级；单标的 |r|>25% → WARN 强制人工核查（**未复权口径下拆分/坏点会产生假跳变，须阻断**）；|r|>50% → FAIL。
- **L5 可复现**：checker 版本+输入哈希+输出报告哈希锚定；同输入重跑**逐位一致**（P1③ 铁律沿用）。

## 五、FAIL 处置

FAIL → ①nav_daily 该行标记待修，写入 decision（RULE_VIOLATION/DATA_CONFLICT）；②DD 层立即切 C 源手工值，政策执行不阻塞；③48h 内定位修复（数据通道/口径/写入器）并重跑；④连续两周 FAIL → 升级群管理员仲裁。

## 六、与 DD 政策的联动边界

- checker **只输出已验证序列与触发读数，不执行降档动作**（动作归政策执行层）。
- D5 单日 −2% 引用线与 R 系日亏损闸：同源同线，§3.6 防双重计分——同一事件只记一次，checker 对账时校验两侧输入一致。
- 本表为**DD 政策专用代理序列**（§1.2 代理宇宙口径），与纸面台账真实持仓净值是两条线，**禁止混写一表**；本表为日线收盘口径，不涉盘中微结构定价，P1③ 执行级规则（OCP/集合竞价）不适用于本表校验。
