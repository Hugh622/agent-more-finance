**編制**：資深量化技術專家｜**日期**：2026-10-11｜**線別**：方法學線 P0
**外部評審原文錨**（評審文件2）：「任何規則進入實盤候選前，應**預先寫下 go/no-go 標準**。若測完後才決定甚麼叫成功，就會重新引入裁量偏誤」——本機制即該鐵律的落地件。

## 一、載體與唯一事實源（零成本已兌現）

1. **登記冊載體＝九表之 `experiment` 表**（MySQL warren_learning_db，全棧 10/11 已建成，第一期生效四表之一）。本機制不新建任何表、不新增任何基建成本。
2. **唯一事實源原則**：試驗以 `experiment` 表行為準；群內討論、MD 文檔只作閱讀視圖。`status` 狀態機：`pre_registered → running → completed / aborted`，**不設 `failed` 逃生門——失敗結論照常寫入 `result_summary` 後落 `completed`**（失敗不入冊＝選擇性報告的溫床）。
3. **防篡改**：每次預註冊生成一份 JSON 快照（欄位見下），計 `sha256` 寫入 `notes`；`pass_criteria` 落庫後**不得 UPDATE**（應用層禁令＋單寫者原則），改門檻＝開新試驗行。

## 二、七條機制條款（本登記冊運行規則）

| # | 條款 | 內容 |
|---|---|---|
| R-1 | **預註冊先於數據接觸** | 回測引擎對該假設的第一次運行，必須晚於 `experiment` 行落庫（status=pre_registered）。時序證據：`experiment.created_at` < 引擎首運日誌時間戳。 |
| R-2 | **go/no-go 一次性寫死** | `hypothesis`（H0＋H1 兩欄）、`primary_metric`、`benchmark`、`pass_criteria`（含最小樣本 n、成本層、判決分位）在預註冊時凍結；completed 時按已凍結門檻機械判決，禁止「結果出來後調整成功定義」。 |
| R-3 | **試驗計數＝多重測試底冊** | 每跑一次參數變體 = 1 trial，`trials_used` 遞增；預註冊時用 `max_trials` 預列全部參數網格。**試驗數（登記冊全域 Σ trials_used）≥30 時，DSR/PBO（CSCV）強制啟用**——在此之前不啟用（評審建議採納），但計數從今天起就有底冊。 |
| R-4 | **peeking 禁令** | completed 前只准寫運行日誌，不准出「中間結論」到群內；若中途發現數據/引擎缺陷必須中止，status=aborted＋notes 記明，修復後**開新行**（-r2 後綴），舊 trial 仍計數——中止不是免費重來。 |
| R-5 | **hit rate 弱化** | 判決依據＝**expectancy（成本後單筆期望值）、profit factor、MAE-MFE 捕獲**；hit rate 僅作分層觀察欄，**永不作 go/no-go 依據**（評審「hit rate 弱化」採納）。 |
| R-6 | **抽屜文件效應條款** | 所有 no-go 結論**必須**在復盤/規則複審時一併陳列；只引用 go 試驗＝違規。排除清單在總回報中固定披露。 |
| R-7 | **治理** | 登記冊 owner＝量化腿；completed 後由輪值紅隊 Validation Gate（首席統合盲審）覆核判決過程；**go 結論僅授權進入 Paper Trading v2 驗證，零實盤授權**（實盤准入仍需用戶終審，沿 v1.2 治理第 4 條）。 |

## 三、預註冊欄位模板（experiment 表逐欄映射）

```
experiment_id   EXP-YYYY-NNN
title           一句話
hypothesis      H0: …（無差異/無優勢原假設，具體可否證）‖ H1: …（方向+幅度+條件）
rule_ids        ["P0.C1@1.2.0","P0.C2@1.2.0",…]（收編映射見 P1② 文檔）
primary_metric  主判指標（計算式寫明：分母/成本口徑/彙總層）
benchmark       比較基準（buy_and_hold / ma_only / fixed_stop / 隨機等待N日）
pass_criteria   GO: …（逐條機械可判）‖ NO-GO: …（任一觸發即否）‖ 最小樣本/分層必報/成本層
max_trials      參數網格預列數（逐格寫在 notes）
status          pre_registered
```

## 四、首批預註冊（三規則族，先註冊後回測）

> 數據窗口（三批共用）：2025-10-03 → 2026-10-09，騰訊 qfq 日K 250 根，全棧標準化層（manifest 凍結見 P1①）。分層必報：**市場（US/HK/CN）× 20日實現波動率三分位**。已知局限誠實標注：①250 根僅覆蓋約一年，「按年份分層」不可行；②樣本宇宙=現行池子（倖存者偏差不可避免，已入總回報局限清單）；③qfq 為 2026-10-10 時點前復權（CRWD 拆股類判例防線：修復段方向可用、幅度存疑——與 v1.2 已有標注一致）。

### EXP-2026-001｜P0 突破確認制 vs「回調接」反事實
- **rule_ids**：P0.C1@1.2.0（收盤越位+0.2%緩衝，收盤=16:00 ET OCP 口徑）、P0.C2@1.2.0（量能≥1.5×20日均量）、P0.C3@1.2.0（三日二守）、P0.E0@1.2.0（事件窗過濾）
- **hypothesis**：H0：池內成本後，P0 確認制入場的單筆 expectancy（R 倍數均值）≤ 0（無優勢）。‖ H1：expectancy > 0 且 bootstrap(1000次) 90% CI 下界 > 0，觸發樣本 n ≥ 40 筆。
- **primary_metric**：成本後單筆 expectancy（R＝初始止損距離；成本見 P2 最低規格三地分參數）。
- **benchmark**：①buy_and_hold（同期同標的）②**回調接反事實**（上升趨勢態 close>MA20 且 MA20 斜率>0，回踩 MA20 收復日入場，同框架退出）——反事實用於回答 9 月復盤「確認制系統性踏空」教訓，輸出為**踏空成本分布**（確認制入場日相對反事實入場日的 20 日前瞻收益差），**不構成本試驗的判決條件**（判決只針對 H0/H1）。
- **pass_criteria**：GO＝H1 成立且 5× 成本層 expectancy 仍 >0。NO-GO＝expectancy ≤0，或 5× 成本層轉負，或 n<40。分層必報：市場×波動三分位全列。
- **參數網格（max_trials=10，預列即凍結）**：突破窗{20,55}×緩衝{0.2%,0.5%}×量能{1.5,1.2}＝8 格＋重跑預算 2。退出統一＝MA 滑動退出（與 EXP-002 共用，保證可對比）。

### EXP-2026-002｜MA 滑動退出/減倉制 vs 固定止損 vs MA-only
- **rule_ids**：P0.C1~C3 同上（入場統一）；退出臂：MA 滑動制（收破 MA20 減半＋連續第二日收破 MA20 清倉）
- **hypothesis**：H0：MA 滑動退出的成本後 expectancy 與 MAE 不優於固定止損 −8%（C11 硬頂）基準。‖ H1：滑動制 expectancy > 0 且（MAE 中位數更小 或 MFE 捕獲率更高），5× 成本層 expectancy 不轉負。
- **primary_metric**：成本後 expectancy；**次級主判**：MFE 捕獲率（平倉收益/MFE）與 MAE 中位數（position_lot 原生欄位）。
- **benchmark**：①fixed_stop −8% ②ma_only（無確認純均線持有，評審文件1同名基準）。
- **pass_criteria**：GO＝H1 成立。NO-GO＝expectancy ≤0，或與兩基準均無改善（Δ≤0 且 MAE/MFE 均不佔優）。
- **參數網格（max_trials=6，預列即凍結）**：{MA20減半+二連破清, MA20減半+MA50清, MA10減半+MA20清, 固定−8%, MA-only, 重跑預算1}。

### EXP-2026-003｜E0 事件窗全日曆回放＋「隨機等待 N 日」反事實
- **rule_ids**：P0.E0@1.2.0（FOMC 決議日 ±1 交易日，窗內只減不加；23/5 事件時刻更新口徑併入）
- **事件日曆（8 次，來源分列）**：2025-10-29、2025-12-10（標準公開會議日程⚠️靜態核對）、2026-01-28、2026-03-18、2026-04-29、2026-06-17、2026-07-29、2026-09-16（`fomc_calendar.json` 靜態配置✅）。
- **design**：全日曆回放＝池內等權虛擬組合，逐事件窗統計「窗內只減不加」的規避回撤（窗內事後 1/3/5 日組合跌幅的避免值）與機會成本（窗內避免掉的漲幅）。**反事實＝隨機等待 N 日**：事件日隨機平移 N∈{1..10} 交易日、種子 42、抽樣 1000 次，構造偽事件窗同統計量分布；真窗統計量落在隨機分布的分位數＝顯著性讀數。
- **hypothesis**：H0：真事件窗的規避效果與隨機等待窗無差異。‖ H1：真窗的事後組合回撤小於隨機窗分布 10% 分位，且機會成本不落在隨機分布最差 25% 分位。
- **pass_criteria**：GO＝H1 成立。NO-GO＝真窗與隨機窗無差異，或機會成本顯著過大（規避收益 < 機會成本 ×1/2）。
- **max_trials=3（預列）**：窗寬{±1(主判), ±2, ±3}。樣本局限誠實標注：8 個事件/250 根窗口，統計力有限，結論以「方向性證據」表述，不作獨立 go 授權（與 EXP-001/002 合併裁量）。

## 五、與九表/判例庫的銜接

1. `experiment.rule_ids` 引用收編後 rule_id（P1② 映射文檔），`validation_experiment_id` 反向掛到 rules 表——go 後規則升 active 的審計鏈自動閉環。
2. 與 **閘A**（v1.2 治理：≥100 筆＋期望值>0）關係：本登記冊 go 授權的是「進入 Paper Trading v2 跑樣本」；閘A 是模擬驗證**完成後**的升格標準——兩者不重疊、先後銜接。
