## 一、硬性前置原則（本規格第一條，不可協商）

> **「凍結層先於回測引擎」**：任何回測/事件回放/Paper Trading 引擎，只准消費凍結層中有凍結記錄且校驗通過的數據；數據文件的身分由 **sha256** 認定，不由路徑/文件名認定。回測結果報告必須引用其所用 run_id＋文件哈希（哈希錨），否則結果視為不可復現、不予收編。

依據（評審文件2）：「**非原子寫檔與無校驗和問題修正**；把台賬、訊號、數據快照、規則版本連成同一條 lineage」——凍結層即 lineage 的數據端錨點。

## 三、凍結記錄規格（側車字段）

```
run_id / type / run_ts           來源批次身分
schema_version                   "2.0-freeze-retro"（本輪現狀凍結）
code_commit                      "v1.0-20261011@0786c312…"（GitHub 基線錨）
code_commit_retro = true         溯源標注：抓取當時未記 commit，按代碼基線回溯錨定（誠實標注，不冒充）
manifest_sha256                  原始 manifest 本體哈希（證據鏈首環）
data_files[]                     path / status / sha256 / bytes / mtime
                                 （kline 類附 actual_rows / actual_last_date 對 manifest 申明核對）
status 枚舉                      frozen（凍結有效）｜missing_superseded（已被修正取代，帶 resolved_path）
                                 ｜mutable_pointer（可變指針，不參與判決）｜missing（真缺失，應為零）
frozen_at                        凍結時刻
```

申明核對結果：`match` 303 條（最新批次申明與現狀一致）；`advanced_overwritten` 1,516 條（歷史批次申明的文件已被後續運行覆蓋推進——**這正是每日覆蓋寫檔模式的固有缺口**，見第五節前向規範）。

## 四、校驗流程（任何人可獨立復核）

```
python3 freeze_manifests.py verify
```
對 33 份側車逐文件重算 sha256 並斷言一致；任何 DRIFT/MANIFEST CHANGED 立即報錯。**回測引擎啟動前調用同一 verify，作為 R-1 時序鐵律的數據側前置檢查。**

## 五、前向 v2-Native 規範（管道改造點，交全棧排期）

| # | 條款 | 內容 |
|---|---|---|
| F-1 | **原子寫檔** | 數據文件先寫臨時文件＋fsync，再 rename 落位（消滅「寫一半」狀態）。 |
| F-2 | **manifest v2 原生** | manifest 生成時即寫入：run_id、code_commit（真實 git hash，禁 retro）、每個數據文件的 sha256、rows/last_date 申明、source_level/grade。 |
| F-3 | **只追加不覆蓋** | 歷史批次數據改存 `archive/<run_id>/` 只追加區；`daily/*.csv` 降級為「最新視圖」，不再是唯一副本——根治 advanced_overwritten 的 1,516 條申明失效問題。 |
| F-4 | **可變指針標注** | latest.csv 類文件在 manifest 中標 `mutable_pointer=true`，凍結層自動排除。 |
| F-5 | **市場快照入冊** | 每次抓取同步寫 `market_snapshot` 表（run_id/schema_version/code_commit/row_count/quality_status），與凍結側車互為鏡像（九表第一期已生效四表之一）。 |

**分級聲明**：本輪 retro 凍結的效力＝「2026-10-11 現狀可校驗」＋「manifest 證據鏈完整」；**不等於**「抓取當時的 point-in-time 快照」。P2 回測的 point-in-time 局限（qfq 2026-10-10 時點前復權等）已在試驗預註冊中誠實標注。

## 六、回測引擎接入約定（P2 直接引用）

1. 引擎數據清單＝池內標的 daily CSV 集（2026-10-11 凍結態）；啟動時跑 verify，哈希錨寫入結果報告頭。
2. 引擎僅消費 status=frozen 文件；missing_superseded 引用按 resolved_path 取用並在報告注明。
3. F-3 落地前，引擎**禁止**在運行中重抓數據（凍結態即測試態）。
