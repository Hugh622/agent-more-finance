## 一、这个团队是什么

一个由多个 AI 角色（Agent）组成的投资研究团队，由一名人类管理员（用户）派单驱动。**团队目标（2026-09-12 确立）：持续研究分析中国内地、香港、美国三地市场**，兼顾地缘政治与政策风向跟踪。

### 团队角色分工

| 角色 | 职责 |
|---|---|
| 管理员（用户） | 派单、终审授权、资金与风险最终决策；安全事项（密钥/权限）由其本人兜底 |
| 群管理员（调度） | 复杂任务拆解派单、进度盘点、跨腿协调与验收通报 |
| 首席投资策略师 | 汇总各腿结论做统合裁决（L4 终审），输出仓位管理与交易计划；治理线与盲审签发人 |
| 宏观基本面研究员 | 宏观经济、政策周期、财报数据、消息面；基本面腿 |
| 资深量化技术专家 | 实时行情挖掘、K线/均线/量价诊断、支撑压力位；技术腿 |
| 全栈开发 | 数据管道、行情抓取工具、监控守护进程、数据库；数据腿 |
| 通用助手 | 档案归档、事实核查、文档支援、图片转录；支援腿 |

### 协作机制（派单—分腿—统合—归档—台账）

1. **管理员派单**（群管理员拆解）→ 各腿独立交付（同一课题出"技术腿/宏观腿/数据腿/支援层"多份独立报告）
2. **签名快照制**（10/11 新增）：数据腿产出签名快照（snapshot id＋品质评分），研究腿引用必须指向 snapshot id——数据层互证保留、结论层隔离，防"多腿同源同错"
3. **首席统合终审**：跨腿交叉互证，冲突项逐条裁决；分歧在解盲后走条件化表态＋首席仲裁（记 MODEL_DISAGREEMENT）
4. **Validation Gate 轮值红队盲审**（10/11 新增）：进场/仓位/规则变更类决策走全盲审——封存信封→按轮值表派发→盲审（≤800字，通过/有保留/不通过）→解盲→首席签发；日度扫描豁免
5. **归档**：全部成果入「研究档案库/」与「research_reports/」
6. **纸面执行台账**：裁决落账为唯一执行依据；10/11 起九表数据库为事实主档，Markdown 台账降为阅读视图（台账 v1.1 仍为现行主档，v2 于 10/16 首次周五周检收编）
7. **定期节奏**：周检（周五滑动复核）、事件驱动（CPI/FOMC/财报裁决点）、G1/G2 双门验收（见第六节）
