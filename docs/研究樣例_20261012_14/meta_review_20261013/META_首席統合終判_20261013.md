## 一、點解要先正名？——「Music Spark」查無此物

用戶口中嘅「Music Spark」**查無此物**，屬訛傳。正名係 **Muse Spark**（2026/4/8 發布，取代 Llama 線）；10/12 再出新模型 **Muse Wonder**（當日 META +3.38%，收 742.96）。個名記歪咗，但件事係真。

## 二、用戶判斷嘅最終裁定：「方向已擺正」✅認同／「有反超架勢」⚠️有保留

**「方向已擺正」——認同，證據鏈齊：**
- MSL 重組＋Alexandr Wang 領軍；
- 棄 Llama 換 Muse 線；
- 發布節奏追貼第一梯隊（4月 Spark／8月 Glimmer／9月 1.3／10月 Wonder）；
- 消費級 agent 開始測收費；
- capex $130-145B＋核電預先行。

**「有反超架勢」——有保留：**
- agentic/coding 跑分有局部第一 claim，但綜合榜唔係頂級（對沖位：有「同價輸 Opus 5.5 九個自家 benchmark」呢條）；
- 財務面硬傷：Q2 FCF $784M（-91%）、EPS 大 miss（$6.18 vs 預期 $7.22）、Q3 指引偏軟——股市而家買嘅係「故事修復」，唔係「業績反超」；
- 價格層兌現咗大半：20日動量 +11.62%，跑贏 MSFT 4.6pt／NOW 13.1pt／QQQ 6.4pt；但距 52 週高 779.82 仲有 -4.7%，MACD 未金叉。

一句：由「差成個身位」追到「平排」，反超要連續兩三季模型＋變現數據先講得出口。

## 三、四態定位點講？——由「貼線」升返「留觀」

- 742.96 收復 MA20（+2.75%），止蝕 713.19 嘅安全墊由唔夠 1% 重建至 -4.01%，收盤確認制下從未觸發；
- 多頭排列（MA10＞MA20＞MA50＞MA200 全升）；
- 短中長分類：**短線**＝強勢修復（看漲）；**中線**＝軟件池大市值組 RS 第一；**長線**＝「方向啱、彈藥夠、成績表未出」——AI 基建優勢係 2027-28 嘅故事，前提係 FCF 斷層修復到。

## 四、執行線：無倉者兩條路／持倉者守止蝕（貼台賬口徑）

| 項目 | 位級／規則 |
|---|---|
| 數據錨收市價 | 742.96（10/12 美收） |
| 半禁區 | 742-752（貼住 R1 食糊位窄，禁追價） |
| R1／R2 | 752.24／779.82 |
| 回落承接帶 | 723-733（MA20＋缺口帶）縮量企穩限價入，單注帽 3% |
| 右側確認 | 放量收＞752.24，上望 779.82 |

- **無倉者兩條路**：a) 等回落 **723-733** 縮量企穩，限價入，單注帽 3%；b) 等**放量收＞752.24** 右側確認再講，上望 779.82。半禁區 742-752 千祈唔好追價。
- **持倉者**：留觀，止蝕 **713.19** 唔使移；減磅線跟 MA20 滑動（當時約 723）。收穿 723＝修復失敗警號；收＜713.19＝機械離場。
- **事件閘**：10/14 CPI 禁新倉、10/24 減壓線、10/27-29 FOMC＋財報牆**只減不加**；主題閘近滿，加注額度要靠 SPCX／NOW 減磅騰。
