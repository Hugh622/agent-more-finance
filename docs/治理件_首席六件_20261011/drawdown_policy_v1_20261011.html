Drawdown Policy 正式条款 v1.0（组合级周频回撤政策）

签发：首席投资策略师｜2026-10-11｜沿革：三地配置模板 v1.0 再平衡触发器「周回撤 5%」雏形 → 本件升格正式条款｜性质：组合级风控层，与标的/市场级三线预警（红 A/B/C）平行不替代｜全程纸面计算，首席可手工重算（可验证性硬约束）

§1 定义与计算口径

1.1 周回撤（Weekly Drawdown, WDD）＝（本周内组合纸面净值最高水位 − 本周五收盘纸面净值）÷ 本周内最高水位最高水位×100%。取正值表述，触发线以「回撤幅度」比较（如 WDD ≥ 5%）。

1.2 净值基准（纸面推演模式专用）：以《纸面执行台账》P 序列假想净值为唯一基准；空仓期（当前状态）以观察池等权指数代理组合（权重＝A核心层 50%／B卫星层 30%／现金 20%），确保空仓阶段政策仍可演练。

1.3 计算时点：每周五收盘后（周检 SOP 固定步骤，首次 10/16）；事件窗（FOMC/财报扎堆周）内允许盘中临时计算但处置动作仍以周检签发为准，紧急情形按 §4.4。

1.4 水位锚定防过敏：以「周内最高水位」为锚，单日跳空造成的深度不重复累计；跨周水位滚动，不得人为重置抹平。

§3 与现行机制衔接（五条，防双重计分）

3.1 与三线预警：红线 A（SPY 748.8 砍半线）/红线 B（10Y≥5.30%）/红线 C（清仓线簇）是标的与市场级即时线，本政策是组合级周频线。两者独立触发、动作叠加、取严者。红线 B 触发的执行闸下调与 L2 下调重叠时，只执行一次不叠加（取更严档）。

3.2 与五闸验收：L2 触发次数与处置及时率计入五闸「纪律遵守 ≥95%」考核；触发后 48h 内未完成规定动作记 EXECUTION_SLIP。

3.3 与事件窗纪律：10/27-29 类「只减不加」窗内触发的 L1/L2，归因复盘须标注事件因素，防止把事件冲击误判为规则失效（归因分流：事件冲击→REGIME_CHANGE 候审；规则未拦→RULE_VIOLATION）。

3.4 与 G1/G2：本政策自 10/16 首次周检起纳入周检 SOP；G2（12/18-20）验收含「政策全周期零漏触发」检查项。

3.5 可验证性硬约束：全部计算首席可手工重算（三档假设收入框架同款原则）；任何工程化实现（覆盖矩阵校验器）输出必须与手工重算一致，不一致以手工为准并立 RULE_VIOLATION。

§4 防滥用与边界（四条）

4.1 不减码规则本身：回撤触发只收紧仓位与节奏，不自动修改任何 C 系列条款与执行线数值——「升格只加纪律不加自由」镜像适用。

4.2 空仓期演练有效：空仓阶段以代理组合演练计算与流程，触发不产生真实动作但必须全流程留痕——政策肌肉记忆属 G2 验收前置。

4.3 时间止损不冲突：SPCX 10/7 类时间止损、个股阶梯减磅等存量规则照常执行，本政策不豁免也不替代。

4.4 紧急通道：事件窗盘中若触发相当于 L2 的深度（盘中临时计算），当值腿可先执行「新仓冻结」单动作，其余处置仍归周检——防临时裁量扩大化。

§5 生效与复检

生效：2026-10-16（首次周五周检）随台账 v2 收编同步生效。复检：每月末随月度复盘复检一次参数（3%/5%/10% 三线与解级条件），修订走 supersedes 链并附判例；未修订即视为追认。版本：v1.0，落库 rules 表 rule_id 收编序列（随 Q-P1-2）。

判例锚：ZETA 清仓后反弹 +21.5% 的「清仓类规则内生代价」在案终判——本政策同样声明：回撤触发的强制减压若遇 V 型反转，机会成本属政策内生代价，不做结果追责，只审计触发与执行正确性。
