## 一、台账字段规范（沿用 v1.0）

| 字段 | 说明 |
|---|---|
| 编号 | P-序号，终身唯一，作废不删、标注状态 |
| 发布日 / 性质 | 令的发布日期；类型＝清仓令/减磅令/禁买令/冻结令/建仓令/挂单令/豁免条款 |
| 触发条件 | 收盘确认制口径（C23精神：以日收盤為準，盤中穿越只發預警） |
| 触发价 / 纸面成交价假设 | 触发日的开盘价或限价区间（滑点假设检验的底稿数据） |
| 纸面盈亏 / 纪律成本 | 推演盈亏；纪律成本＝因守规则而放弃的收益（机会成本），只记录、不追责 |
| 状态 | 待触发 / 已触发（纸面）/ 已关闭 / 已作废 |
| 复盘标记 | 纳入周检对账与G1/G2验收统计（触发正确率、纪律遵守率、滑点偏差） |
