## 已锁定的设计事实（与协议 v1.1 互洽）
- 交易几何：21:00 ET → 次日 20:00 ET 连续 23h；每日唯一停机 = 维护窗 20:00-21:00 ET；
  周线：周日 21:00 开 → 周五 20:00 收（周五维护窗并入 49h 周末断层）。
- 收盘锚：日线收盘判定只认 **16:00 ET 官方收盘竞价**；S1 实践 = 腾讯/新浪双引擎
  官方 print 互证（专项 16:00 锚拉，**非**腾讯日K字段——防口径污染，最硬风险点）。
- 生效锚：日历激活 ≥2026-12-06（自启后未生效 = 无害空转）；真锚 T-0 = 实际首个
  隔夜段日；存档核验 **T-0+1（部分）/ T-0+2（终锁）**，周六自动顺延至周日。
- 三源校验：S1 官方 print / S2 新闻收评 / S3 web_search 快照（第四源仅为交叉验证
  冗余，不动摇判定主线；12-08 试，结果在报告中明示）；
  S1+任一源 ±0.1% = verified；无 S1 需全源一致；<2 源 = insufficient；否则人工复核。
- DST 互洽（已固化为单测）：冬令隔夜 = 10:00-17:00 HKT（有限重叠试运行）；
  2027-03-14 夏令起 = 09:00-16:00 HKT（港A全程覆盖，满血节点）；
  维护窗 HKT 对应：冬 09:00-10:00 / 夏 08:00-09:00。
- 监控钟：每日 10:00 与 05:00 HKT 两刻钟；夏令移位 09:00 / 04:00（2027-03-14 起）。
- 输出契约（供量化腿）：新增两栏——隔夜量归属（喂 C2 锚定验证）、缺口率
  （进 N1 压力位校准）；12/7 首日数据回填后由量化腿做一次技术面复核。

## 文件
- `windows.py` — 维护窗成员判定、bar 边界切齐（bar 不跨窗）、ET↔HKT DST 映射

- `verify.py` — 16:00 官方收盘锚三源校验
- `tests/test_pipeline.py` — 全部单测（pytest 或直接 `python3 tests/test_pipeline.py`）
